# 🚀 Deploy Rápido no Netlify - 3 Passos

## ⚡ Método Mais Rápido (Sem Configuração)

### Passo 1: Acesse o Netlify
👉 **https://app.netlify.com**

### Passo 2: Conecte seu Repositório
1. Clique em **"Add new site"**
2. Escolha **"Import an existing project"**
3. Escolha seu Git (GitHub/GitLab/Bitbucket)
4. Autorize e selecione: **`master-league-f1`**

### Passo 3: Deploy Automático
1. O Netlify detectará automaticamente:
   - ✅ Build: `npm run build`
   - ✅ Publish: `dist`
2. Clique em **"Deploy site"**
3. Aguarde 2-5 minutos
4. **PRONTO!** Seu site estará no ar 🎉

---

## 📍 Seu Site Ficará Em:
`https://[nome-aleatorio].netlify.app`

Você pode personalizar o nome depois em: **Site settings** → **Change site name**

---

## ✅ Pronto!
Não precisa fazer mais nada. O Netlify fará tudo automaticamente!

**Tempo total: ~5 minutos** ⏱️
