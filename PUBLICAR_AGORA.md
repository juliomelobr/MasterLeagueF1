# 🚀 Publicar Site no Netlify - AGORA

## ⚡ Método Rápido (5 minutos)

### Passo 1: Acesse o Netlify
👉 **https://app.netlify.com**

### Passo 2: Faça Login
- Se não tem conta, clique em **"Sign up"** (é grátis)
- Pode fazer login com GitHub

### Passo 3: Conecte seu Repositório
1. Clique no botão **"Add new site"** (canto superior direito)
2. Escolha **"Import an existing project"**
3. Clique em **"GitHub"**
4. Autorize o Netlify (se pedir)
5. Procure e selecione: **`master-league-f1`**

### Passo 4: Configure (Já está configurado automaticamente!)
O Netlify vai detectar automaticamente:
- ✅ **Build command:** `npm run build`
- ✅ **Publish directory:** `dist`
- ✅ **Branch:** `main`

**NÃO PRECISA MUDAR NADA!** Só clique em **"Deploy site"**

### Passo 5: Aguarde
- O build leva 2-5 minutos
- Você verá o progresso em tempo real
- Quando terminar, seu site estará no ar! 🎉

---

## 📍 Seu Site Ficará Em:
`https://[nome-aleatorio].netlify.app`

Você pode ver o link assim que o deploy terminar!
