🚀 COMEÇAR AGORA (40 min no total)

Passo 1: SUPABASE (5 min)
  1. Ir para: https://app.supabase.com
  2. Abrir: SQL Editor
  3. Criar: New Query
  4. Colar: Conteúdo de supabase-schema.sql
  5. Executar: Ctrl+Enter

Passo 2: PILOTOS (10 min)
  1. Opção A: python3 scripts/import_pilotos.py
  2. Opção B: INSERT INTO pilotos ... (SQL manual)
  3. Opção C: Via UI Supabase (Table Editor)

Passo 3: EMAIL (15 min)
  1. Supabase > Functions > New Function: send-email
  2. Colar código de: SUPABASE_SETUP.md
  3. Supabase > Settings > Secrets (adicionar 3):
     • SMTP_HOST=smtp.gmail.com
     • SMTP_USER=juliomelobr@hotmail.com
     • SMTP_PASS=<app_password_do_gmail>
  4. Deploy

Passo 4: TESTAR (5 min)
  1. npm run dev
  2. Abrir: http://localhost:5173/analises
  3. Fazer login
  4. Enviar acusação
  5. Verificar email
