📋 FLUXO DE FUNCIONAMENTO
═══════════════════════════════════════════════════════════════════════════════

  PILOTO A                    →    ACUSAÇÃO ENVIADA
  ├─ Preenche form                 ├─ Gera STW-C190301
  ├─ Clica "Enviar"               ├─ Insere em Supabase
  └─ Recebe confirmação            ├─ Envia 3 emails
                                   └─ Log criado
                                   
                                   ↓
                                   
  PILOTO B                    →    DEFESA ENVIADA
  ├─ Clica "Enviar Defesa"        ├─ Insere em Supabase
  ├─ Responde acusação            ├─ Atualiza status
  └─ Recebe confirmação            ├─ Envia 2 emails
                                   └─ Log criado
                                   
                                   ↓
                                   
  STEWARD                     →    VEREDITO PUBLICADO
  ├─ Analisa acusação+defesa      ├─ Calcula pontos (0-25)
  ├─ Emite veredito               ├─ Aplica race_ban (>20)
  └─ Publica resultado             ├─ Insere em Supabase
                                   ├─ Envia 2 emails
                                   └─ Log criado
                                   
                                   ↓
                                   
  QUALQUER PILOTO             →    CONSULTA LANCE
  ├─ Acessa "Consultar Lances"    ├─ Vê acusação vs defesa
  ├─ Visualiza vídeos              ├─ Vê resultado final
  └─ Confirma informações          └─ Vê pontos + race ban

🆘 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

  ❌ Tabelas não encontradas?
     → Executar supabase-schema.sql no SQL Editor
     
  ❌ Pilotos não aparecem no dropdown?
     → Inserir dados em tabela pilotos (usar import_pilotos.py)
     
  ❌ Email não está chegando?
     → Verificar secrets SMTP (SMTP_HOST, SMTP_USER, SMTP_PASS)
     → Verificar Supabase > Logs > Edge Functions
     
  ❌ Erro ao enviar acusação?
     → F12 > Console > ver erro específico
     → Verificar RLS policies
     
  ❌ Deadline não funciona?
     → Verificar timezone BRT (UTC-3)
     → Testar: console.log(new Date()) vs getBRTDeadline()
